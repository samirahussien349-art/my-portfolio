## ✏️ كيف تقومين بتخصيص معلوماتك؟

افتحي ملف `js/config.js` في أي محرر نصوص (مثل VS Code أو Notepad):

1. **اسمك وتخصصك**:
   ```javascript
   personal: {
     name: "Sara Ahmed",                   // اسمك هنا
     brandName: "Sara.dev",                 // الاسم الذي يظهر في أعلى الموقع
     title: "Frontend Developer",           // وظيفتك
     location: "Cairo, Egypt",              // بلدك
     email: "sara.developer@example.com",   // بريدك الإلكتروني
     cvLink: "path-or-link-to-your-cv.pdf"  // رابط الـ CV
   }
   ```

2. **روابط حساباتك (GitHub, LinkedIn, Twitter)**:
   عدلي الروابط في مصفوفة `socials` لتشير إلى بروفايلاتك الحقيقية.

3. **إضافة مشاريعك الخاصة**:
   في مصفوفة `projects`، يمكنك إضافة مشاريعك أو تعديل المشاريع الموجودة:
   ```javascript
   {
     title: "اسم المشروع",
     category: "react", // react أو javascript أو ui
     description: "وصف مختصر للمشروع وما يقدمه",
     tags: ["React", "Tailwind CSS"],
     image: "رابط صورة المشروع أو مسار الصورة",
     liveDemo: "رابط المعاينة المباشرة للمشروع",
     github: "رابط الكود على جيتهاب"
   }
   ```

## 🌐 كيف ترفعين موقعك مجاناً على الإنترنت؟

### الطريقة الأولى: GitHub Pages (الأشهر والأسهل مجاناً)
1. قومي بإنشاء مستودع جديد على **GitHub** باسم: `username.github.io` أو `my-portfolio`.
2. ارفعي ملفات هذا المجلد بالكامل إلى المستودع.
3. ادخلي على **Settings** > **Pages** واختاري الفرع `main` ثم اضغطي **Save**.
4. سيصبح موقعك متاحاً على الإنترنت برابط خاص بك خلال دقيقة! 🎉

### الطريقة الثانية: Vercel أو Netlify
1. افتحي حساباً مجانياً على [vercel.com](https://vercel.com) أو [netlify.com](https://netlify.com).
2. اسحبي مجلد الموقع (Drag & Drop) أو اربطيه بمستودع GitHub.
3. سيتم نشر الموقع فوراً مع توفير شهادة SSL مجانية وسرعة خارقة.
